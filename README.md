# 🕒 IST Live Clock

A minimal, fullscreen digital clock that displays **Indian Standard Time (IST)** in real-time.

Built using plain HTML, CSS, and JavaScript. No frameworks, no dependencies, just clean and lightweight.

---

## Demo https://ist.puter.site

---

## 🚀 Features

- Displays current **IST time (HH:MM:SS AM/PM)**
- Updates every second ⏱️
- Fullscreen **dark mode UI**
- Custom font for aesthetic display
- Zero external JS libraries
